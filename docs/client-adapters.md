# 客户端适配器开发

客户端声明和检测位于 `src-tauri/src/clients.rs`，结构化生成、预览、写入与恢复位于 `src-tauri/src/config.rs`。

每个适配器需要声明唯一 ID、显示名称、平台、命令检测方式、候选配置路径、支持协议、支持等级、自动写入能力、重启要求和手动引导。

自动写入适配器还必须：

1. 使用对应格式的结构化解析器。
2. 尽量保留未知字段；不能保留注释时在预览中警告。
3. 预览时记录目标文件 SHA-256；应用时重新校验以检测外部修改。
4. 写入前创建带时间戳的备份。
5. 使用目标目录内临时文件、同步落盘和平台原子替换。
6. 失败时恢复备份，并尽可能将权限限制为当前用户。
7. 不直接修改编辑器或扩展的内部数据库。

只有公开稳定配置格式和本机字段均得到核对后，适配器才能标为 `verified`。无法确认时使用 `experimental` 或 `manual`。
