# 协议适配器开发

协议探测位于 `src-tauri/src/protocol.rs`。适配器必须遵守以下契约：

1. 规范化 URL，但保留用户显式输入的 HTTP。
2. 不把 API Key 放入 URL、日志或错误文本。
3. 优先请求模型列表或元数据；确需验证工具 schema 时，只发送明确标记、最多输出 1 token 的最小请求，并在 UI 提前说明可能产生极少量费用。
4. 为 401、403、404、429、5xx、DNS、TLS、代理和超时提供中文摘要。
5. 仅根据响应状态、响应头和 JSON 结构判断协议；URL 特征只能用于 Azure 等明确入口的辅助判断。
6. 返回模型能力时区分服务端明确字段、已知规则和未知状态。

新增适配器时，在 `ProtocolKind` 增加类型，创建独立 `probe_*` 函数，并加入探测顺序。测试必须使用 mock server，覆盖成功、身份验证失败、接口不存在、限流、超时和密钥脱敏，不得依赖真实 API Key。
