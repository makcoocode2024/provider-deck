# 安全设计

Provider Deck 采用本地优先设计，不启用遥测，也不向用户 Base URL 之外的服务器上传 Provider、模型、URL 或密钥。

API Key 由 `keyring` 写入平台安全凭据库，Provider 状态只保存凭据 ID。探测请求把密钥放在协议规定的请求头；Gemini 同样使用 `x-goog-api-key`，避免 URL 查询参数。前端只在表单提交期间持有明文，并默认使用密码输入框。

配置写入默认关闭。关闭“只生成配置”后，应用会展示目标路径、脱敏前后预览、明文存储风险和重启要求。写入采用外部修改校验、备份、原子替换和失败回滚。

诊断输出只包含平台、架构、版本、凭据库类型与客户端安装状态。分享前仍应人工检查用户名、路径和代理地址。
