## Purpose

按端点与模型定位推理能力探测结论，并汇总当前用户配置下哪些自定义档位适配这个模型，供界面一次取齐所需信息，避免界面自行推断能力或复算兜底优先级。

## ADDED Requirements

### Requirement: 按端点与模型汇总推理探测结论

系统 SHALL 提供一个只读查询，输入服务标识与模型标识，返回该模型在该端点下的推理探测结论汇总。返回内容 MUST 只包含既有探测流程已经得出的事实，不得由模型名称、参数量、显存或任何名称形态推断出新的能力结论。

查询 MUST 在无法定位服务或模型时返回明确错误，而不是返回一个"未探明"的空结论——空结论会被界面当成事实展示。

#### Scenario: 已探明能力的模型

- **WHEN** 该模型在该端点已有探测结论且结论为支持推理
- **THEN** 返回的原生参数形态字段 MUST 指出探测到的参数类别（effort 枚举 / token 预算 / 布尔开关）
- **AND** 返回的协议清单 MUST 与探测结论一致
- **AND** 不得因为本次查询而改写该模型已存的能力结论或置信度

#### Scenario: 未探明能力的模型

- **WHEN** 该模型在该端点没有探测结论，或结论为未探明
- **THEN** 原生参数形态字段 MUST 表达"未探明"而不是任何具体参数类别
- **AND** 内置档位兼容标记 MUST 表达"无法确认"，不得标成兼容

#### Scenario: 服务不存在

- **WHEN** 传入的服务标识在库中不存在
- **THEN** 查询 MUST 返回错误
- **AND** 错误消息中 MUST NOT 包含 API 密钥的任何片段

### Requirement: 匹配当前模型的全部自定义档位

系统 SHALL 用用户已保存的模型名匹配规则筛选出适配当前模型的**全部**自定义档位，而不是只返回第一条命中的规则。

匹配 MUST 大小写不敏感；空匹配串 MUST NOT 参与匹配；规则引用的档位已被删除时该条规则 MUST 被跳过而不报错。返回顺序 MUST 与用户规则表的顺序一致——那个顺序就是用户表达的优先级。

匹配结果 MUST NOT 写入模型的能力结论，也 MUST NOT 影响置信度。用户写下的规则是用户的设定，不是探测到的事实。

#### Scenario: 多条规则命中同一模型

- **WHEN** 用户的规则表中有两条以上规则都能命中该模型，且各自引用的自定义档位都存在
- **THEN** 返回的匹配档位列表 MUST 按规则表顺序包含全部命中项
- **AND** 每一项 MUST 携带足以让界面展示的档位名与命中说明（哪条规则、哪种匹配方式）

#### Scenario: 规则引用了已删除的档位

- **WHEN** 某条命中的规则引用的自定义档位已被删除
- **THEN** 该条 MUST 被跳过
- **AND** 查询 MUST 继续检查后续规则，不得中断也不得报错

#### Scenario: 没有任何规则命中

- **WHEN** 用户没有写任何规则，或没有规则能命中该模型
- **THEN** 匹配档位列表 MUST 为空列表
- **AND** MUST NOT 用任何默认档位填充该列表

### Requirement: 探测结果的时效缓存

系统 SHALL 缓存探测结果，使界面在同一模型上的重复查询不会重复触发网络请求。缓存 MUST 按端点与模型共同定位——同一模型 ID 在不同端点下是两条独立记录。

缓存过期后再次查询 MUST 允许重新探测。缓存 MUST NOT 存储 API 密钥、请求体或响应体。

旧版本写出的状态文件在缺少缓存字段时 MUST 能正常加载，加载后视为无缓存。

#### Scenario: 缓存命中

- **WHEN** 同一服务与模型在缓存有效期内被再次查询
- **THEN** MUST 直接返回缓存结论
- **AND** MUST NOT 发出任何出站请求

#### Scenario: 换端点后缓存不复用

- **WHEN** 同一模型 ID 出现在另一个端点下并被查询
- **THEN** MUST NOT 复用另一端点的缓存结论

#### Scenario: 旧状态文件加载

- **WHEN** 加载一份不含探测缓存字段的旧状态文件
- **THEN** 加载 MUST 成功
- **AND** 用户已保存的自定义档位、名称规则、逐模型兜底 MUST 一条不丢

### Requirement: 查询不改动实时请求行为

本查询 MUST NOT 改变实时业务请求的推理参数行为。能力未探明时实时请求仍 MUST 省略推理参数；查询返回的匹配档位 MUST 只影响配置文件写出与界面展示。

#### Scenario: 未探明模型的实时请求

- **WHEN** 某模型能力未探明，但用户已有能命中它的自定义档位规则
- **THEN** 实时请求的推理参数 MUST 仍为省略
- **AND** 配置写出层 MAY 按用户设定的档位写入参数
